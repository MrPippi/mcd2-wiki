## 特色

- **資料來自遊戲本身**：名稱、說明與數值都從遊戲的 DataTable 與多語系檔抽取，對應**遊戲版本 1.1.3.0**。
- **16 種語言**：遊戲文字使用官方翻譯，和遊戲裡看到的一樣。
- **中英對照**：每個名稱和說明都可以多顯示一種語言。
- **不用猜的**：資料無法說明的數值會先不上架，或標示為未確認。
- **免費、免註冊**：靜態網站，手機也好用。

## 可以查什麼

| 分類 | 內容 |
| --- | --- |
| **近戰與遠程武器** | 連擊中每一擊的傷害、硬直、距離與擊退，武器的定位與重量，可能出現的效果與 I／II／III 級數值，以及依威脅等級計算的效果出現機率 |
| **護甲** | 每一套護甲與各部位，含部位、說明、獨特版本與效果出現機率 |
| **神器** | 冷卻時間、靈魂消耗、持續時間與範圍，以及可能出現的效果與出現機率 |
| **護符** | 每一級的數值，與升到下一級所需的經驗值 |
| **附魔** | I／II／III 級數值，以及哪些附魔書會出現 |
| **效果** | 所有效果與各等級數值 |
| **狀態** | 燃燒、冰凍、中毒等狀態的增益／減益類型、預設持續時間與數值修正、狀態融合，以及會施加它的神器、附魔、效果與怪物 |
| **怪物圖鑑** | 每隻怪物的頭像、生命值、韌性、各項抗性、靈魂產量與掉落，含靈魂腐化版本，以及出沒區域 |
| **靈魂附魔** | 靈魂腐化怪物生成時可能帶有的增益，各等級的數值，以及哪些怪物或競技場不會出現 |
| **世界地圖** | 主世界、隙浮與營地，標出礦車站、裂隙、傳送雕像、商人、主線與支線任務、風暴產生器、護符寶箱、地下城與區域名稱 |
| **靈魂風暴** | 目前與下一場風暴的即時倒數（以你的時區顯示）、區域輪替與各區風暴產生器的位置數、風暴產生器的難度、生命值與護盾，以及獎勵寶箱的內容 |
| **配裝** | 選好武器、護甲、神器與護符組成一套配裝，整套的效果與附魔集中列出（同一效果出現在多件裝備時顯示合計），複製連結分享（打開就是同一套），或下載成圖片貼到社群 |
| **武器比較** | 最多三把武器並排比較連擊傷害、射速、距離、硬直、內建效果與可出現的效果，標出最佳值，可用連結分享 |
| **掉落機率計算器** | 選物品、威脅等級、難度與稀有度，查每個來源（寶箱、任務獎勵、頭目與一般怪物）掉出它的機率 |
| **攻略** | 依遊戲資料整理的機制：商販升級花費與解鎖、附魔花費與升級、稀有度效果與掉落權重、威脅等級與難度、秘密護符、貨幣上限與各劇情階段建議等級；資料無法說明的部分標示為未確認 |
| **任務** | 依劇情順序排列的主線任務、依地區分組的支線任務、回聲魔像任務與頭目重戰；每個任務列出目標、前置任務、解鎖的任務、首次與每次完成的獎勵、依任務規模給的綠寶石，以及會遇到的怪物。物品頁會標出獎勵來自哪個任務 |
| **地點** | 每個區域一頁：區域圖示與遊戲為該區域設定的玩家等級（遊戲有提供時）、地圖有標記時的地圖位置連結、區域內的地點、依類型分組的出沒怪物、區域任務與區域掉落物。怪物頁與任務頁會連到所屬區域 |
| **頭目** | 依劇情順序排列的 10 個頭目與 6 個小頭目，附上生命值、所在區域，以及出現的主線任務與頭目重戰（遊戲資料有記載時） |
| **成就** | 所有 Steam 成就與全球達成率；隱藏成就要你自己點開才會顯示解鎖條件，不怕被劇透 |
| **更新日誌** | 遊戲各版本的更新重點（依新增／變更／修正與主題分組）與官方說明連結，標出本站資料對應的版本；本站資料換版時列出數值變動 |

物品頁也會列出取得方式（任務獎勵、寶箱、商人或附魔書池）與各來源的掉落機率。

## 好用的功能

- **中英對照**：打開右上角的「對照英文」，每個名稱和說明下方會多一行英文（英文版網站則對照繁體中文）。跟用英文玩的朋友溝通、看英文攻略時特別方便。
- **全站搜尋**：在任何頁面都能用中文或英文名稱搜尋。
- **清單篩選**：輸入文字縮小範圍，或只看「一般」、「獨特」物品。
- **分享地圖位置**：地圖網址會記住世界、縮放與位置，直接把網址傳給朋友就能看到同一個地方。標記可以篩選，也能搜尋地點。
- **鍵盤快速鍵**：按 Q／E 切換上一個／下一個物品分類，地圖按 Z／X 切換世界，和遊戲裡一樣。
- **手機也好用**：每一頁都有針對小螢幕的版面。

物品名稱、說明等遊戲文字都取自遊戲官方的多語系檔，和你在遊戲裡看到的一樣。網站自己的文字（選單、標籤、註解）繁體中文與英文為人工撰寫，其他語言為機器翻譯；確認翻錯的句子會改顯示英文。

## 常見問題

**為什麼數值和實際遊玩看到的不一樣？**

網站顯示的是遊戲資料檔裡的基礎值，實際遊玩時會受難度、隊伍人數與裝備強度影響。

**為什麼沒有出手時間、每秒傷害這類資料？**

有些資料不在遊戲資料表裡。每一擊的出手時間與每秒傷害存在動畫檔中，所以網站不顯示。無法從資料算出數值的條目會先不上架，不用猜的。

**遊戲改版後網站會更新嗎？**

會。遊戲改版時，會重新從新版遊戲檔案抽取資料來更新網站。資料對應的版本標在本頁最上方。

**發現錯誤要怎麼回報？**

請開一則 [Issue](https://github.com/MrPippi/mcd2-wiki/issues/new/choose) 並選擇對應的表單，附上頁面網址，並說明你在遊戲中看到的內容；有截圖更好。使用問題或功能建議請到[討論區](https://github.com/MrPippi/mcd2-wiki/discussions)。
