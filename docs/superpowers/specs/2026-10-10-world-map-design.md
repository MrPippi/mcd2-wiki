# Minecraft Dungeons II 繁中 Wiki — 世界地圖設計規格

- 日期：2026-10-10
- 狀態：待審
- 基準：`master`（`e0296bc`，PR #8 合併後）；分支 `feat/world-map`（worktree `.claude/worktrees/world-map`）
- 使用者選擇：全圖＋標記；標記含區域傳送點、礦車站、商人、區域名稱／室內入口；Overworld、Sift、Camp 三個世界全做；Leaflet＋圖塊金字塔

## 1. 目標

新增一個可縮放、可拖曳的世界地圖頁，底圖用遊戲自己的俯視全圖，上面標出傳送點、礦車站、商人、區域名稱與室內區域入口，可依種類篩選與依名稱搜尋。

### 1.1 成功標準

1. `/zh/map/`、`/en/map/` 顯示 Overworld 全圖，可滑鼠滾輪／觸控縮放與拖曳；只載入畫面內的圖塊。
2. 世界分頁切換 Overworld／Sift／Camp，網址以 `?world=` 記錄；無效值退回 Overworld。
3. 網址 hash `#z/x/y` 記錄縮放與中心點，重新整理或分享後回到同一視角。
4. 五種標記（區域傳送點、礦車站、商人、區域名稱、室內區域）各有勾選框（附數量），取消勾選即隱藏該類；選擇記在 `localStorage`，讀寫失敗不影響頁面。
5. 標記名稱搜尋：輸入後列出符合者，點選即飛到該標記並開啟其說明；無結果顯示「找不到」。
6. 點室內區域標記顯示名稱與該區域小地圖。
7. 中英切換保留 `?world=` 與 hash。
8. 標題列與首頁分類列各有「地圖」入口。
9. 無 JavaScript 或 Leaflet 載入失敗時，顯示該世界的縮小全圖與「需要 JavaScript 才能互動」提示。
10. 手機寬度（360px）無橫向捲軸，篩選面板移到地圖下方。
11. `npx tsc --noEmit` 無錯誤，單元測試與 E2E 全部通過。

### 1.2 非目標

- 地下城內部（`DT_WorldTeleportPoints_Tile`，約 100 筆）與 Debug 傳送點。
- 物品掉落位置、怪物分布、任務標記。
- 從條目頁連到地圖位置（之後再做）。
- 迷霧／探索遮罩（`*WorldMap.png` 全白，判斷為遮罩，不使用）。

## 3. 座標換算

### 3.1 假設

- `Bounds` 單位為方塊；`Location` 單位為 cm，÷100 得方塊。
- `MapDims` 為小地圖像素（Overworld 小地圖 1544px，等於 `MapDims`），即 1px＝1 方塊。
- BeautyRender 全圖覆蓋同一個方形範圍，邊長 `MapDims`（可能再除以 `FancyMapSizeRatio`），以 `MinPos` 為原點；世界兩軸中較短的一軸在方形內的偏移與軸向（X/Y 是否對調、是否翻轉）待驗證。

### 3.2 驗證（實作第一步）

挑 3–4 個肉眼可辨識的地標（Overworld 營地傳送點、城鎮傳送點、沙漠要塞入口；Sift、Camp 各一個傳送點），把座標畫到拼好的全圖上：

- 通過：每個地標落在實際位置 ±16px 內（以 8192px 全圖計）。
- 不通過：調整軸向、偏移、`FancyMapSizeRatio` 的套用方式，直到通過；最終參數寫進 `src/data/map.json` 的每個世界設定，不在前端硬寫。
- 三個世界中任一個無法在 ±16px 內對齊時，停下來回報使用者，不出貨該世界的標記。

### 3.3 介面

`src/lib/map/transform.ts`（純函式）：

```ts
type WorldFrame = {
  minX: number; minY: number;   // 方塊
  span: number;                 // 方塊，全圖邊長
  swapAxes: boolean; flipX: boolean; flipY: boolean;
  imageSize: number;            // 全圖像素（Overworld 8192）
};
export function toImagePixel(frame: WorldFrame, block: { x: number; y: number }): { px: number; py: number };
export function isInside(frame: WorldFrame, block: { x: number; y: number }): boolean;
```

## 4. 架構

### 4.1 圖塊 `scripts/assets/map-tiles.ts`（新檔，接在 `npm run assets`）

- 用 sharp 讀 1024px 原圖，切成 256px webp 圖塊，輸出 `public/map/<world>/<z>/<x>/<y>.webp`（world 用小寫 `overworld`、`sift`、`camp`）。
- 最高層級 `zMax = ceil(log2(imageSize / 256))`，該層一像素等於原圖一像素；往下每層縮一半，到整張圖一塊為止。邊緣不足 256px 的圖塊補透明。
- 原圖的 mtime 與大小都沒變時跳過該世界（記在 `public/map/<world>/manifest.json`）。
- 任一 `<row>_<col>` 缺檔：腳本失敗並列出缺的檔名。
- 室內小地圖轉 webp 輸出到 `public/map/indoor/<slug>.webp`。
- 新增 devDependency `sharp`（明確宣告，不依賴 astro 的間接安裝）。

### 4.2 標記 `scripts/extract/map.ts`（新檔，接在 `npm run extract`）

輸出 `src/data/map.json`：

```ts
type MapData = {
  worlds: Record<"overworld" | "sift" | "camp", {
    frame: WorldFrame;
    zMax: number;
    markers: Marker[];
  }>;
};
type Marker = {
  id: string;                                   // 來源列名稱，穩定
  kind: "teleport" | "minecart" | "merchant" | "area" | "indoor";
  x: number; y: number;                         // 方塊座標
  name: { zh: string; en: string };
  icon?: string;                                // public/ 下的路徑
  minimap?: string;                             // indoor 才有
};
```

- 傳送點 `Level` → 世界；`Level` 不屬三個世界者丟棄。
- 區域名稱標記：位置取該區域所有區域傳送點的平均；沒有任何傳送點的區域不標。若驗證時發現資料表另有區域範圍，改用範圍中心。
- 室內區域：位置取 `Bounds` 中心。
- 問題寫進現有 `issues.ts` 報告並排除該標記：超出全圖範圍、名稱查不到、礦車站 tag 對不回。

### 4.3 頁面 `src/pages/[lang]/map/index.astro`（新檔）

- 讀 `map.json` 渲染外框、世界分頁、篩選面板、`<noscript>` 備援縮圖（z0 圖塊）。
- `?world=` 由 client 讀取（靜態站，build 時無 query）；伺服器端先渲染 Overworld。

### 4.4 元件 `src/components/WorldMap.astro`（新檔）

- 版面：上方世界分頁（樣式同 `CategoryTabs`）；主區地圖，桌機約 75vh，底色沿用米白點陣板；側欄篩選＋搜尋，`max-width` 以下移到地圖下方。
- 標記：傳送點、礦車站、商人用遊戲 icon，無 icon 時用 `UiIcon`＋朱紅色；區域名稱為文字標籤，縮放 ≥ `zMax - 2` 才顯示；室內區域點擊開啟 popup（名稱＋小地圖）。

### 4.5 前端程式 `src/lib/map/`（新目錄）

| 檔案 | 職責 |
|---|---|
| `transform.ts` | 座標換算（§3.3） |
| `markers.ts` | 依種類篩選、依名稱搜尋（純函式，回傳新陣列） |
| `view-state.ts` | 解析／序列化 `?world=` 與 `#z/x/y`，無效值回預設 |
| `viewer.ts` | client 進入點：建立 Leaflet `CRS.Simple` 地圖、圖層、篩選、搜尋、hash 同步 |

- 新增 dependency `leaflet@1.9.4`，只在地圖頁 import。

### 4.6 既有檔案修改

- `src/components/SiteHeader.astro`：搜尋框旁加「地圖」連結。
- `src/components/HomeHero.astro`：`category-grid` 在 `TAB_ORDER` 迴圈之後加一個 `<li>`「地圖」，編號接續分類，預覽區放 Overworld z0 縮圖（非 `TAB_ORDER` 成員，不影響分類分頁）。
- `src/lib/i18n.ts`：新增地圖相關字串（世界名、標記種類、找不到、需要 JavaScript）。

## 5. 部署與大小

- CI 沒有 `source-data`，`public/map/` 與 `src/data/map.json` 需 commit，同現有 `public/icons/`。
- 預估三個世界 webp 圖塊合計 10–15MB。實作時量實際大小；超過 20MB 先降 webp 品質，仍超過再捨棄最高層級並回報。

## 6. 錯誤處理與邊界

- 抽取：超出範圍、名稱缺、tag 對不回 → 報告並隱藏（與 PR #8 規則一致）。
- 圖塊：缺檔 → 腳本失敗，不靜默跳過。
- 前端：Leaflet 初始化失敗 → 顯示備援縮圖；`localStorage` 讀寫包 try/catch；`?world=` 無效 → Overworld；hash 無效 → 預設視角；搜尋無結果 → 「找不到」。
