# Minecraft Dungeons II 繁中 Wiki — 遊戲風格改版設計規格

- 日期：2026-10-10
- 狀態：待審閱
- 基準：`master`（PR #1 合併後）
- 視覺方向與版面已在瀏覽器比較中由使用者選定；未明說的細節依建議方案決定（使用者指示「依照建議進行」）。

## 1. 目標

把網站從目前的通用深紫色版面，改成接近遊戲 UI 的視覺語言，並同時改善條目頁可讀性、導覽、首頁與手機體驗。**資料、抽取管線、網址結構都不變。**

### 1.1 使用者的選擇

| 項目 | 選擇 |
|---|---|
| 整體風格 | **遊戲原味**：深藍綠底、標題列面板、橘色強調、方角 |
| 字型 | **標題像素字、內文一般字**：中文標題／標籤用俐方體 11 號，英文標籤用 Silkscreen，內文用系統字型 |
| 導覽 | **遊戲物品欄分頁**：標題列下一排分類圖示分頁，Q／E 鍵切換，手機可左右滑 |
| 列表頁 | **物品欄＋名稱**：物品格下方顯示中文名稱；桌機滑過或聚焦時側邊說明面板；手機點一下從底部滑出說明，再按「查看」進條目頁 |
| 條目頁 | **資訊欄＋內容**：左側資訊欄（大圖示＋重點資訊表），右側分段內容 |
| 首頁 | **標題橫幅＋分類格**：像素字大標題、置中搜尋框、一排分類物品格 |

### 1.2 成功標準

1. 全站換成 §2 的配色與字型；所有頁面方角、無紫色殘留。
2. 每頁標題列下有分類分頁；目前分類發亮；桌機按 Q／E 切換分類（輸入框中不觸發）；手機分頁列可水平捲動。
3. 列表頁：物品格下方有名稱；桌機滑過／聚焦任一物品時側邊面板顯示該物品說明；手機點物品不會直接跳頁，而是滑出說明面板，按「查看」才進條目頁；沒有 JS 時物品仍是一般連結。
4. 條目頁為資訊欄＋內容兩欄（≥ 900px），手機堆疊；條目大圖示不延遲載入。
5. 首頁為標題橫幅＋分類格。
6. 切換語言時保留 `?q=` 與 `#錨點`。
7. 字型自行託管，含授權檔；部署在子路徑（`BASE_PATH`）時字型與圖示網址仍正確。
8. 既有功能（中英對照、搜尋、篩選、外框、獨特標記、未發布分類 404、連結全通）全部維持；單元與 E2E 測試全過。

### 1.3 非目標

- 不改資料、抽取管線、網址、分類範圍。
- 不新增前端框架或 CSS 框架。
- 不做淺色模式。

## 2. 視覺系統

### 2.1 配色（取自遊戲截圖）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B1A20` | 頁面背景 |
| `--surface` | `#10222A` | 面板 |
| `--surface-2` | `#1C2B31` | 標題列、面板標頭、按鈕 |
| `--border` | `#2C3B42` | 邊框（2px） |
| `--text` | `#E8E2D8` | 主要文字 |
| `--muted` | `#8FA3AA` | 次要文字、英文對照 |
| `--accent` | `#FF7E2F` | 強調、獨特物品、目前分頁 |
| `--link` | `#8FD6E0` | 內文連結 |
| `--radius` | `0` | 全站方角 |

物品格、附魔書框、神器欄、獨特標記（既有 `frames` 樣式）不變。

### 2.2 字型

| 角色 | 字型 | 來源 |
|---|---|---|
| 中文標題、標籤、物品名 | 俐方體 11 號（Cubic 11） | 自行託管 `src/assets/fonts/cubic-11/Cubic_11.woff2`（約 400 KB，OFL 1.1），經 Vite 打包以支援 `BASE_PATH` |
| 英文標籤、區塊標題、kicker | Silkscreen | `@fontsource/silkscreen`（OFL 1.1），由 Astro 打包 |
| 內文 | 系統字型（Noto Sans TC、Microsoft JhengHei…） | 不下載 |

- `font-display: swap`，載入前以系統字型顯示。
- 授權檔：`public/licenses/Cubic-11-OFL.txt`，頁尾連結「字型授權」。

### 2.3 共用元素

- **面板**：`--surface` 底、2px `--border` 邊框；可選標頭列（`--surface-2`，Silkscreen 大寫英文、置中）。
- **區塊標題**：Silkscreen 英文大寫（如 `DESCRIPTION`）＋中文（像素字），下方 1px 邊線。
- **kicker**：物品上方的 Silkscreen 小字，如 `UNIQUE MELEE WEAPON`。英文單數名稱：近戰 `MELEE WEAPON`、遠程 `RANGED WEAPON`、護甲 `ARMOR`、神器 `ARTIFACT`、護符 `TALISMAN`、附魔 `ENCHANTMENT`、效果 `EFFECT`；獨特版前加 `UNIQUE `；護甲套裝為 `ARMOR SET`／`UNIQUE ARMOR SET`。
- **按鈕**：方角、2px 邊框；按下狀態以橘色邊框表示。

## 3. 全站框架

### 3.1 標題列

左：像素字站名（連回首頁）。中：搜尋表單（`GET /{lang}/search/?q=`）。右：「中英對照」切換與語言切換。手機時搜尋框收成一行置於站名下方。

### 3.2 分類分頁列

- 標題列下方，置中一排 7 個分類圖示（遊戲分類圖示，`.site-nav`），順序：近戰、遠程、護甲、神器、護符、附魔、效果。
- 每個分頁是連結；文字標籤為視覺隱藏、滑過／聚焦時以浮動標籤顯示；目前分類 `aria-current="page"` 並以橘色光暈與底線標示。
- 桌機左右各顯示 `Q`／`E` 鍵帽；按 Q／E 前往前一個／下一個分類（循環）。目前頁面不屬於任何分類時（首頁、搜尋），E 到第一個、Q 到最後一個。焦點在輸入框、文字區域、可編輯元素，或按著 Ctrl／Alt／Meta 時不觸發。
- 手機（寬度 < 700px）：隱藏鍵帽，分頁列可水平捲動，目前分頁自動捲入可視範圍。
- 頁面以 `Base` 的 `current` 屬性告知目前分類：分類頁、條目頁、護甲套裝頁與單件頁都傳入所屬分類。

### 3.3 頁尾

維持非官方聲明與資料來源，加上字型授權連結，改用面板樣式。

### 3.4 語言切換

伺服端仍依路徑產生對應語言網址；載入後與 `hashchange` 時，以腳本把目前的 `location.search` 與 `location.hash` 附加到語言切換連結。

## 4. 頁面

### 4.1 首頁（標題橫幅＋分類格）

- 橫幅：Silkscreen kicker `UNOFFICIAL FAN WIKI`、像素字大標題（站名）、置中搜尋表單。
- 分類格（`.category-grid`）：7 個分類，每個是物品格內放分類圖示，下方中文名稱與數量。
- 底部沿用頁尾。

### 4.2 分類列表頁（物品欄＋名稱＋說明面板）

- 標題：分類圖示＋像素字分類名＋數量；篩選列沿用（文字篩選、有獨特物品時顯示一般／獨特）。
- 版面（≥ 900px）：左為物品格網格，右為固定寬度、隨捲動固定（sticky）的說明面板；< 900px 只有網格。
- 物品（`.entry-card`）：物品格（既有外框）＋下方中文名稱（像素字，獨特為橘色）。保留 `data-names`、`data-variant` 供篩選。
- 每個物品內含 `<template>`，預先渲染說明面板內容：kicker、名稱（含英文對照）、描述（已白名單化 HTML）、「查看完整條目 ›」連結。
- 桌機（`(hover: hover)`）：`mouseenter`／`focusin` 時把該物品的 template 內容放進側邊面板；點擊照常進入條目頁。初始時面板顯示提示文字。
- 觸控（`(hover: none)`）：點物品時阻止跳頁，把 template 內容放進底部說明面板（`role="dialog"`）並顯示，「查看 ›」按鈕連到條目頁；關閉按鈕與 Esc 關閉；再點同一物品直接進條目頁。
- 無 JS：物品即一般連結。
- 護甲列表：同樣版面，物品為套裝（以第一件部位的圖示），說明面板列出各部位名稱。

### 4.3 效果頁

沿用表格（保留 `#slug` 標題錨點供搜尋子結果），改為面板樣式：表頭 `--surface-2`、列分隔 `--border`。

### 4.4 條目頁（資訊欄＋內容）

- 最上方 kicker（如 `UNIQUE MELEE WEAPON`）。
- ≥ 900px 兩欄：左欄 260px 資訊欄（sticky），右欄內容；< 900px 堆疊（資訊欄在上）。
- 資訊欄：
  - 大圖示（160px，`loading="eager"`，容器 `.entry-head`）。
  - 重點資訊表 `<dl class="facts">`：分類（圖示＋連結到分類頁）、稀有度（一般／獨特）、部位（護甲）、所屬套裝（連結）、未翻譯標記（若有）。
- 內容：
  - 名稱 `h1`（像素字，含英文對照）。
  - 區塊：`DESCRIPTION · 描述`、`DETAILS · 詳細說明`（長描述）、`UNLOCK · 解鎖`（若有）、`ENCHANTMENT BOOK · 附魔書`（附魔）、`RELATED · 相關條目`（另一版本、所屬套裝，附小物品格）。
- 護甲套裝頁：資訊欄為 2×2 部位小物品格＋稀有度、部位數；內容為套裝名稱與各部位（沿用 `set-piece`）。

### 4.5 搜尋頁

Pagefind UI 以 CSS 變數套用配色與方角，搜尋框改用像素字型標題。
